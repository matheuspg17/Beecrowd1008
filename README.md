# Resolução exercicio Beecrowd1008
## Descrição do problema
Escreva um programa que leia o número de um funcionário, seu número de horas trabalhadas, o valor que recebe por hora e calcula o salário desse funcionário. A seguir, mostre o número e o salário do funcionário, com duas casas decimais.
## Como Funciona
1. O usuário insere o identificador numérico do funcionário (`numeroF`) e as horas (`horaT`) como inteiros.
2. O usuário insere o valor por hora (`salarioH`) como ponto flutuante.
3. O código calcula o salário final através da multiplicação: `salarioH * horaT`.
4. O programa imprime o número do funcionário e o salário calculado formatado via `System.out.printf`.
